# 산출물 5. 포팅 매뉴얼 상세

## 1. Gitlab 소스 클론 이후 빌드 및 배포할 수 있도록 정리한 문서

### 1) 시스템 환경 및 주요 제품 버전
- **JVM**: Java 21 LTS (Eclipse Temurin 21)
- **Framework (WAS)**: Spring Boot 3.5.11 (Embedded Tomcat)
- **Web Server**: Nginx (alpine)
- **Database**: MySQL 8.0
- **In-Memory Cache**: Redis (alpine)
- **Monitoring**: Grafana
- **Frontend (Android)**: Kotlin 2.0.21, Android Gradle Plugin 9.0.1, Jetpack Compose 2024.09.00
- **IDE**: IntelliJ IDEA 2024.x (BE 권장), Android Studio Ladybug/Koala (FE 권장)

### 2) 빌드 시 사용되는 환경 변수 상세 내용
운영 환경 서버스 구동 및 젠킨스 빌드 파이프라인(`Jenkinsfile`)에서 주입되는 주요 환경 변수 스펙입니다. (`.env` 혹은 Jenkins Credentials 영역에 저장됨)

#### Database (MySQL)
- `DB_HOST`: 데이터베이스 접속 호스트 (기본 `mysql` 컨테이너 망 사용)
- `DB_PORT`: 데이터베이스 접속 포트 (기본 3306)
- `DB_NAME`: 사용할 애플리케이션 데이터베이스 이름
- `DB_USERNAME`: 데이터베이스 접속 계정명
- `DB_PASSWORD`: 데이터베이스 접속 비밀번호
- `DB_ROOT_PASSWORD`: MySQL 관리용 Root 계정 비밀번호

#### Redis
- `REDIS_HOST`: 레디스 접속 호스트 (기본 `redis`)
- `REDIS_PORT`: 레디스 접속 포트 (기본 6379)

#### JWT (JSON Web Token)
- `JWT_SECRET`: JWT 토큰 암복호화를 위한 시크릿 키 문자열
- `JWT_ACCESS_EXPIRY_MS`: Access Token 만료 시간 (ms 단위)
- `JWT_REFRESH_EXPIRY_MS`: Refresh Token 만료 시간 (ms 단위)

#### 외부 서비스 (External Services) 연동 키
- `KAKAO_REST_API_KEY`: 카카오 디벨로퍼스 앱 REST API 키
- `KAKAO_ADMIN_KEY`: 카카오 디벨로퍼스 앱 어드민 키 (서버 간 강제 푸시 메세지 발송 등에 적용)
- `AGORA_APP_ID`: Agora WebRTC 애플리케이션 ID
- `AGORA_APP_CERTIFICATE`: Agora WebRTC 애플리케이션 인증키

### 3) 배포 시 특이사항
- **자동화된 무중단 배포 (Blue-Green Deployment)**: Jenkins 파이프라인(`Jenkinsfile`)을 통해 소스 클론부터 Docker 빌드, Blue-Green 컨테이너 교체까지 자동화되어 있습니다.
- **Health Check 기반 Nginx 스위칭**: 새롭게 띄워진 컨테이너(Blue 또는 Green)는 `nc -z` 명령을 통해 8080 포트의 정상 기동 여부를 헬스체크한 후 최종적으로 Nginx의 `upstream.conf`를 덮어쓰고 reload 처리됩니다.
- **인프라 컨테이너 사전 기동 구조**: 프로젝트 앱 컨테이너 운영 전 의존성을 가지는 MySQL, Redis, Nginx, Grafana 컨테이너가 우선 실행됩니다(`docker-compose.yml` 내 `prod` 프로필)
- 환경 변수 파일(`.env`)은 보안상 코드 저장소에 업로드(`추가로 업로드하지 않아도 됩니다` 정책 부합)되지 않으며, 배포 파이프라인 구축 시 젠킨스의 `ENV_FILE` 시크릿(secret text/file)으로 개별 등록되어 동작합니다.

### 4) 프로젝트(ERD)에 활용되는 주요 계정 및 프로퍼티 정의 파일 목록
- `shutter-BE/src/main/resources/application-prod.yaml`: 운영망(EC2 로컬/Docker 배포) 전용 런타임 프로퍼티 파일 (DB 커넥션 설정, JPA/Hibernate 속성, Swagger UI 비활성 처리 등)
- `shutter-BE/docker-compose.yml`: Nginx Proxy 구조 및 Spring Boot Blue/Green, 인프라 컨테이너 프로비저닝 명세서. 환경 변수를 주입받아 각 컨테이너를 설정
- `shutter-BE/Jenkinsfile`: 전체 CI/CD 플로우와 서버 Shell 스크립트 구동 규칙 기술
- `shutter-BE/mysql-init.sql`: 데이터베이스 기동 시점에 초기 셋업용 스키마 스크립트

## 2. 프로젝트에서 사용하는 외부 서비스 정보 문서

#### (1) 카카오 오픈 API (Kakao Developers)
- **활용 목적**: 프로젝트 앱 내 보호자·피보호자의 소셜 로그인, 보호자 목록 조회(톡 친구 API), 카카오 알림 푸시(Message API)
- **가입 및 설정 정보**
  - 카카오 디벨로퍼스(Kakao Developers)에 어플리케이션 신규 등록 및 앱 키 발급
  - 내 애플리케이션 > 플랫폼 내 **Android 플랫폼** 추가 후, 로컬 개발/릴리즈용 **키 해시** 등록 절차 필수
  - **활용 키 정보**
    - `Native App Key`: Android SDK 초기화 및 Client Login 인가 사용
    - `REST API Key`: 백엔드 통신 및 인증 토큰 발급
    - `Admin Key`: 백엔드 시스템 내에서 보호자 대상 긴급 메시지 발송 등 관리자 권한용 API
  - **[중요 - 주의사항]**: 현재 카카오 애플리케이션이 **'테스트 앱'** 상태이거나 **'비즈니스 앱 전환(검수)'**을 온전히 받지 않은 상태인 경우, 사전에 [팀원/테스터]로 등록되지 않은 평가위원의 일반 카카오 계정으로는 로그인이 거부되거나 톡 친구 API(메시지 발송 등) 권한이 제한될 수 있습니다. 
    - **원활한 평가를 위해, 함께 제출(또는 안내)해 드리는 '테스트용 카카오 계정'으로 로그인해 주시기 바랍니다.**

#### (2) 아고라 클라우드 (Agora WebRTC)
- **활용 목적**: 사용자 간 저지연 1:1 라이브 화상 통화 구현
- **가입 및 활용 정보**
  - Agora 콘솔 가입 후 신규 프로젝트를 생성하여 `App ID`와 `App Certificate`를 획득
  - 보안을 위해 안드로이드 클라이언트가 통화방(채널)에 접속할 때 필요한 토큰은 **백엔드 서버**를 거쳐 고유하게 발급받아 입장(`io.agora:authentication` 라이브러리로 Token Builder 활용)

#### (3) 파이어베이스 (Firebase / FCM)
- **활용 목적**: 피보호자의 딥페이크 사기 의심 상황 시 등록된 보호자 앱으로의 긴급 백그라운드 푸시 알람 전송 및 이벤트 연동
- **가입 및 활용 정보**
  - Firebase 콘솔에 새 프로젝트(또는 구글 클라우드 연동) 생성 및 Android 패키지 등록 (`com.s14p21a404.shutter`)
  - 생성된 `google-services.json` 설정 파일을 Android 앱 모듈 루트(`app/`)에 삽입
  - 프로젝트 설정 등급에서 서버 연동용 서비스 계정 키를 획득하여 푸시 토큰 관리에 맵핑 구현 (단말의 Push Token에 대해 타겟팅 푸시 발행)
