## 2. 구현 완료된 기능

### 2-1. 메인 화면 (`MainActivity`)

- **권한 요청 UI**: `READ_PHONE_STATE`, `POST_NOTIFICATIONS` 권한을 런타임에 요청
- **서비스 토글**: "보호 시작" / "보호 중지" 버튼으로 감지 서비스 ON/OFF
- **상태 표시**: 서비스 실행 여부에 따라 "🟢 보호 활성화" / "⚪ 보호 비활성화" 카드 표시
- **권한 미충족 시**: 주황색 "권한 허용하기" 버튼 노출 → 권한 허용 후 서비스 시작 가능

### 2-2. 영상통화 감지 서비스 (`VideoCallDetectService`)

- **Foreground Service** (`foregroundServiceType=specialUse`)로 백그라운드 상시 동작
- **`START_STICKY`**: 시스템에 의해 종료되어도 자동 재시작
- **통화 상태 감지**: `TelephonyCallback.CallStateListener`로 통화 상태 실시간 모니터링
    - `CALL_STATE_IDLE (0)` → 대기
    - `CALL_STATE_RINGING (1)` → 수신 중
    - `CALL_STATE_OFFHOOK (2)` → 통화 중
- **카메라 사용 감지**: `CameraManager.AvailabilityCallback`으로 카메라 점유 상태 모니터링
    - `onCameraAvailable` → 카메라 사용 가능 (미사용)
    - `onCameraUnavailable` → 카메라 사용 중 (다른 앱이 점유)
- **영상통화 판단 로직**: `통화 중(OFFHOOK)` + `카메라 사용 중` = **영상통화로 판단**
- **중복 방지**: `AtomicBoolean`으로 모달 중복 표시 방지, 통화 종료 시 자동 초기화
- **상태바 알림**: "Shutter 보호 활성화 - 영상통화를 모니터링 중입니다." 상시 노출

### 2-3. 경고 다이얼로그 (`WarningDialogActivity`)

- **투명 테마**: `Theme.Shutter.Dialog` (투명 배경 + NoActionBar)로 다이얼로그처럼 표시
- **경고 UI** (Compose):
    - ⚠️ 경고 아이콘
    - "영상통화 감지" 제목 (빨간색)
    - "영상통화가 감지되었습니다. 딥페이크 분석을 시작합니다." 설명
    - "주의: 상대방 영상이 조작되었을 수 있습니다." 경고 텍스트
    - 빨간색 "확인" 버튼 → 누르면 닫힘
- **반투명 배경**: 바깥 클릭 시 닫기 가능

## 5. 동작 흐름

```
사용자가 앱 실행
    → 권한 요청 (전화 상태, 알림)
    → "보호 시작" 버튼 클릭
    → VideoCallDetectService 시작 (Foreground)
    → TelephonyCallback + CameraCallback 등록
    → 백그라운드에서 상시 모니터링
    
영상통화 수신/발신
    → TelephonyCallback: OFFHOOK (통화 중)
    → CameraCallback: onCameraUnavailable (카메라 사용 중)
    → evaluate(): 두 조건 모두 충족 → 영상통화 판단
    → WarningDialogActivity 실행 → 경고 모달 표시
    
통화 종료
    → TelephonyCallback: IDLE (대기)
    → dialogShown 초기화 → 다음 감지 준비
```
