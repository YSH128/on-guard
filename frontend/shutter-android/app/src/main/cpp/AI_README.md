> **OnGuard** : 실시간 딥페이크 탐지 · 음성 분석 · 대화 위험도 판단을 온디바이스 + 클라우드 하이브리드로 구현한 AI 파이프라인

## 1. Background

### 문제 상황

보이스피싱 범죄는 매년 수천억 원 규모의 피해를 낳고 있으며 최근에는 **생성형 AI 기반 딥페이크** 기술을 이용해 지인의 얼굴을 실시간으로 합성하여 영상통화를 시도하는 신종 수법이 급증하고 있다. 피해자 입장에서는 영상을 보고도 가짜임을 인지하기 매우 어려운 상황이다.

| 기존 문제 | Shutter의 접근 |
|---|---|
| 딥페이크 여부를 사람이 육안으로 판별해야 함 | 온디바이스 딥페이크 감지 모델로 자동 판별 |
| 의심 통화 중 대화 내용을 실시간으로 분석하는 도구 없음 | 온디바이스 STT + LLM 기반 위험 키워드 자동 태깅 |
| 피해자가 금융 앱에 접근해도 알림 없음 | 딥페이크 감지 + 금융 앱 접근 시 즉시 차단 오버레이 |
| 감지 결과를 가족·지인에게 전달하는 방법 없음 | 카카오톡 보호자 알림 + GPS 위치 공유 |

### 개발 과정에서의 기술적 전환 — 입모양(Lip Reading) → 자체 앱 STT

초기에는 **영상에서 입모양을 추출하여 대화 내용을 파악**하는 Visual Speech Recognition(VSR) 방식을 시도했다.

그러나 두 가지 근본적인 한계가 존재

1. **한국어 입모양 인식의 정확도 한계** — 기존 공개 VSR 모델은 영어권 데이터 기반으로 학습되어 있어 한국어 음소에 대한 정확도가 실사용 수준에 미치지 못했다.
2. **외부 통화 앱의 음성 스트림 접근 불가** — 일반 갤럭시 전화 통화, 카카오톡 보이스톡은 OS 보안 정책상 다른 앱이 오디오 스트림을 직접 캡처할 수 없다. 결과적으로 **소리 없이 영상 프레임만** 확보 가능한 상황에서 입모양만으로 한국어를 인식하는 것은 현실적으로 불가능했다.

이 한계를 극복하기 위해 **자체 영상통화 앱(Agora RTC 기반)을 직접 개발**했다. 자체 앱 안에서는 SDK 레벨에서 오디오 스트림(`IAudioFrameObserver`)에 직접 접근이 가능하므로, 혼합 음성 데이터를 PCM 형태로 추출하여 온디바이스 Whisper STT로 연결하는 파이프라인을 완성했다.

```
[포기한 방향]                      [채택한 방향]
외부 통화 앱 (갤럭시 / 카카오톡)      자체 앱 (Agora RTC)
    │                                   │
    │ 영상 프레임만 캡처 가능              │ 오디오 스트림 직접 접근
    ▼                                   ▼
입모양 추출 (VSR)               Whisper BASE STT (온디바이스)
    │                                   │
한국어 정확도 불충분 → ✗         위험 태그 분류 (LLM) → ✓
```

## 2. Key Features & System Architecture

### 2-1. Vision Model — 딥페이크 감지 (ForensicAdapter)

```
영상통화 화면
    │  (1초 간격 스크린캡처, MediaProjection)
    ▼
ROI(얼굴 영역) 추출
    │  (OpenCV, C++ Native)
    ▼
ForensicAdapter 추론  ←─ face_deepfake_v6.onnx
    │  INT8 양자화 | NNAPI: HTP → GPU → CPU 폴백
    ▼
10프레임 평균 → 딥페이크 확률
    │
    ├─ 임계값 초과 → 경고 오버레이 + 보호자 알림
    └─ 미달 → 대기 후 재추론
```

- **모델**: 사전 학습된 딥페이크 검출 모델 (ForensicAdapter) — PyTorch → ONNX 변환
- **최적화 상세**:
  - `INT8 양자화`로 모델 크기 축소 → 발열 감소 및 추론 속도 개선 (추론 속도 약 **40% 감축**)
  - `NNAPI` 기반 HTP → GPU → CPU 자동 폴백 (일반적으로 GPU 사용) → 추론 속도 약 **75% 감축**
  - Qualcomm Snapdragon 탑재 기기에서는 QNN 최적화 경로 추가 지원
  - CAM(Channel Activation Map) 출력을 통해 가짜 의심 영역 시각화 가능
- **최종 추론 시간 (1 batch)**: **약 8초**
- **모델 웜업**: 앱 설치 후 첫 실행 시 자동 런타임 적재 (적재 완료까지 약 20초)

---

### 2-2. Voice Model — 온디바이스 STT (Whisper BASE)

```
Agora RTC 오디오 프레임
    │  (onMixedAudioFrame, 16kHz · Mono · 1024 samples)
    ▼
ByteArray 누적 버퍼 (~4초 간격)
    │
    ▼
WhisperKit (Qualcomm AI Hub 최적화 Whisper BASE)
    │  CPU + HTP 혼합 할당 | 30초 청크 단위 추론
    ▼
텍스트 결과 (누적 STT)
    │
    └──▶ Language Model로 전달
```

- **모델**: [Qualcomm AI Hub](https://aihub.qualcomm.com/) 공개 Whisper BASE (Qualcomm 칩 최적화)
- **SDK**: `WhisperKit` (argmaxinc) — 자동 모델 다운로드 및 초기화
- **온디바이스 처리**: 음성 데이터가 서버로 전송되지 않아 **개인정보 보호** 가능
- **자체 앱 통화 전용**: Agora RTC SDK를 통해 수신한 오디오 스트림에서 직접 추출
- **STT 추론 소요 시간**: 약 14초 (STT + LLM 합산)

---

### 2-3. Language Model — 대화 위험도 분류 (GPT-4o-mini via GMS)

```
누적 STT 텍스트
    │
    ▼  (텍스트 변경 감지 시에만 API 호출 — 불필요한 호출 최소화)
GMS API (gpt-4o-mini)
    │  시스템 프롬프트: 4개 카테고리 분류
    ▼
위험 태그 반환
    #금융거래 | #개인정보요구 | #특정장소유인 | #일상대화
    │
    ├─ 위험 태그 감지 시 → 금융 앱 차단 오버레이에 태그 표시 (누적 유지)
    └─ 일상대화 → 표시하되 위험 태그 우선 유지
```

- **모델**: GPT-4o-mini (SSAFY GMS 프록시 경유)
- **분류 카테고리**: `#금융거래`, `#특정장소유인`, `#개인정보요구`, `#일상대화`
- **효율화 전략**: STT 결과 텍스트에 변화가 발생했을 때만 API를 호출하여 비용 최소화
- **태그 유지 로직**: 위험 태그가 한 번이라도 감지되면 이후 `#일상대화`가 와도 위험 태그 유지

---

### 2-4. 딥페이크 영상 생성 (inswapper_128) — 테스트·데모용

- **모델**: 사전 학습된 FaceSwap 모델 `inswapper_128`
- GPU 서버를 이용해 Agora RTC 서비스를 통한 **실시간 딥페이크 영상 송출**
- 정면 얼굴 사진 수집 후 Face Swap 처리 → 테스트용 딥페이크 통화 생성
- 생성형 영상 서비스를 통해 만든 Fake Video를 업로드하여 송출하는 방식도 지원

## 3. Usage — 모델 파일 설정

### 딥페이크 감지 모델 (수동 설치 필요)

Whisper는 앱 실행 시 자동으로 다운로드되지만, **딥페이크 감지 모델은 별도로 다운로드** 후 지정 경로에 배치해야 합니다.

**1. 모델 다운로드**

아래 Google Drive 링크에서 `face_deepfake_v6.onnx` 파일을 다운로드합니다:

```
https://drive.google.com/drive/folders/1GjIa639kj6JfeqcrfLXEPH8L_xLmlJyM
```

**2. 파일 배치**

다운로드한 파일을 아래 경로에 넣습니다:

```
S14P21A404/
└── frontend/
    └── shutter-android/
        └── app/
            └── src/
                └── main/
                    └── assets/          ← 여기에 face_deepfake_v6.onnx 배치
                            face_deepfake_v6.onnx
```

> ⚠️ 파일명이 정확히 `face_deepfake_v6.onnx` 이어야 합니다. 이름이 다를 경우 앱이 모델을 로드하지 못합니다.

### Whisper STT 모델 (자동 다운로드)

WhisperKit SDK가 앱 첫 실행 시 **자동으로 모델을 다운로드**합니다. 별도 설치 불필요. 단, 첫 실행 시 네트워크 연결이 필요합니다.

## 4. Technical Highlights

### 왜 온디바이스인가?

| 항목 | 서버 추론 | 온디바이스 (Shutter) |
|---|---|---|
| 개인정보 | 음성/영상 데이터 서버 전송 필요 | 기기 내 처리, 외부 전송 없음 |
| 응답 속도 | 네트워크 레이턴시 포함 | 즉각 처리 |
| 통화 중 사용 가능성 | 네트워크 불안정 시 불가 | 네트워크 무관 |
| 비용 | API 호출 비용 발생 | 무료 (기기 리소스 사용) |

### 추론 성능 최적화 요약

| 최적화 기법 | 효과 |
|---|---|
| INT8 양자화 | 추론 속도 약 40% 감축 |
| NNAPI (HTP→GPU→CPU 폴백) | 추론 속도 약 75% 감축 |
| Qualcomm QNN 경로 | Snapdragon 기기 추가 최적화 |
| 앱 시작 시 모델 웜업 | 통화 시작 즉시 추론 가능 |
| STT 텍스트 변화 감지 시만 LLM 호출 | API 비용 최소화 |

### 실시간 처리 타임라인 (통화 시작 기준)

```
0s ──── 앱 시작 시 딥페이크 모델 웜업 시작
       20s ──── 딥페이크 모델 적재 완료, 추론 대기
       30s ──── 첫 번째 STT 청크 완료
       37s ──── 첫 번째 LLM 위험 태그 결과 수신
 (이후 4초마다 STT, 변경 시 LLM 호출)
```
