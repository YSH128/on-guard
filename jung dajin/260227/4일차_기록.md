## 특강 정리 : VLM & 모델 경량화 (Model Compression)

### 1. VLM (Vision Language Model) 개요
VLM은 이미지(Visual)와 텍스트(Language) 데이터를 동시에 이해하고 처리하는 멀티모달 모델입니다.

구조적 특징:

Vision Encoder: 이미지를 특징 벡터(Patch Embeddings)로 변환 (예: ViT).

Adapter/Connector: 시각적 특징을 언어 모델이 이해할 수 있는 차원으로 매핑 (예: MLP, Perceiver Resampler).

Language Model (LLM): 입력된 텍스트와 이미지 정보를 결합하여 최종 답변 생성.

주요 학습 단계:

Pre-training: 대규모 이미지-텍스트 쌍 데이터를 통한 정렬(Alignment).

Instruction Tuning: 사용자의 지시사항을 따르도록 미세 조정(Fine-tuning).

### 2. 모델 경량화 필요성
최신 VLM은 파라미터 수가 방대하여 연산 비용이 높고 추론 속도가 느립니다. 이를 해결하기 위해 경량화가 필수적입니다.

Latency 개선: 실시간 서비스(온디바이스 AI) 구현.

Memory 절약: 고가의 GPU 자원 소모 최적화 및 모바일 기기 탑재 가능.

Energy Efficiency: 전력 소모 감소를 통한 지속 가능성 확보.

### 3. 주요 경량화 기법 (Optimization Techniques)
1) 양자화 (Quantization)
개념: 가중치(Weights)의 정밀도를 낮추어(예: FP32 → INT8/INT4) 용량을 줄이는 기법입니다.

효과: 메모리 사용량을 1/4 이하로 절감하며 연산 속도를 가속화합니다.

2) 지식 증류 (Knowledge Distillation)
개념: 거대 모델(Teacher)의 지식을 작은 모델(Student)에게 전수하는 방식입니다.

효과: 작은 파라미터 수로도 대형 모델에 근접한 성능을 유지합니다.

3) 가지치기 (Pruning)
개념: 성능에 기여도가 낮은 가중치나 뉴런을 제거합니다.

효과: 모델의 Sparse한 구조를 만들어 불필요한 연산을 줄입니다.

4) 효율적인 구조 설계 (Efficient Architecture)
개념: 처음부터 연산량이 적은 구조로 설계합니다.

예시: MobileNet의 Depthwise Separable Convolution, LoRA(Low-Rank Adaptation) 등

## AI 딥페이크 모델 찾기
# 딥페이크 (판단 + ROI)

## 딥페이크 기술

단순히 이미지가 가짜인가? 를 넘어서서 픽셀(공간), 흐름(시간), 신호(주파수) 세가지 차원에서 조작의 흔적을 찾아낸다

## 딥페이크 탐지의 핵심 영역

### 1. 공간적 분석 (Spatial Domain)

이미지 한 장 안에서 발생하는 시각적 오류를 찾아냄

- 경계선 왜곡(Blending Artifacts): 얼굴을 붙인 경계면이 미세하게 흐릿하거나 계단 현상이 생기는 부분
- 텍스처 불일치: 눈 주변과 뺨의 피부 질감이 다르거나, 생성형 AI 특유의 미세한 노이즈(Checkerboard artifacts) 패턴
- 생리학적 오류: 홍채의 반사광이 양쪽 눈에서 다르거나, 치아의 디테일이 뭉개지는 현상

### 2. 시간적 분석 (Temporal Domain)

영상이 재생될 때 프레임 사이의 연결성을 분석함

- 프레임 일관성: 고개를 돌릴 때 얼굴 가면이 미세하게 떨리거나 위치가 어긋나는 현상
- 비정상적 움직임: 눈 깜빡임 주기, 입 모양과 음성의 미세한 싱크 오차(Lip-sync error)
- 생체 신호(rPPG): 실제 혈류에 따른 얼굴색의 미세한 변화(심박수)가 영상 전체에서 일관되게 나타나지 않는 경우

### 3. 주파수 분석 (Frequency Domain)

사람 눈에는 보이지 않지만 수학적 변환(FFT/DCT)을 통해 드러나는 기계적 흔적을 찾아냄

- 고주파 결함: AI가 이미지를 생성(Up-sampling)할 때 발생하는 특정한 주파수 대역의 이상 신호
- 압축 흔적: 진짜 카메라가 찍은 영상과 AI가 생성한 영상의 데이터 압축 방식 차이

## 선정 모델

모델 명 : https://github.com/QingyuLiu/Exposing-the-Deception

선정 이유:

1. 얼굴의 각 부위가 물리적으로 서로 조화를 이루는지를 보는 Self-consistency를 핵심적으로 분석함
    1. 국소 특징 추출(Local LIBs): 얼굴을 겹치지 않는 여러 구역으로 나누어 각 부분의 특징을 독립적으로 추출함
    2. 전역 특징 융합(Global Fusion): 추출된 각 부위가 하나의 '진짜 얼굴'로서 논리적으로 맞는지 비교함
        - *예: "코의 그림자 방향과 턱의 그림자 방향이 일치하는가?"*
    3. 위조 마스크(Forgery Mask) 생성: 일관성이 깨진 부위를 특정하여 픽셀 단위로 좌표를 찍고 이 좌표가 ROI가 됨
2. weight 가 존재
3. 실제 세계의 저화질, 노이즈 환경 데이터셋에서도 다른 모델 대비 성능 좋음
4. 2025.10 발표 모델로 최신 생성 AI 기법인 diffusion 등에 대한 방어 로직 포함됨

### 모델의 한계점 및 대응

- 한계: 실시간 영상 통화 시 조명이 매우 어둡거나 네트워크 환경이 불안정할 경우 오탐지 가능성 있음
- 대응: 'Temporal Smoothing(시간적 평활화)' 기법 적용
    - 단일 프레임이 아닌 연속된 5~10프레임의 결과를 종합하여 작동 여부를 결정함으로써 오작동을 방지하는건 어떤지?
