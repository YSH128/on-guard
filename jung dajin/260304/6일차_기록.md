## NDK, JNI 학습 내용 정리
### 1. NDK (Native Development Kit)
NDK는 안드로이드 앱에서 C 및 C++ 코드를 사용할 수 있게 해주는 도구 모음

성능 최적화: Java/Kotlin보다 실행 속도가 빠른 C/C++을 사용하여 CPU 연산 집약적인 작업(영상 처리, 오디오 분석)을 수행

라이브러리 재사용: OpenCV, TensorFlow Lite(C++ API), FFmpeg 등 기존에 C++로 작성된 강력한 오픈소스 라이브러리를 그대로 가져와 사용할 수 있다는 장점을 가짐

하드웨어 접근: NPU나 GPU 가속을 위한 저수준 API에 직접 접근하여 딥러닝 모델의 추론 지연 시간(Latency)을 최소화

### 2. JNI (Java Native Interface)
JNI는 Java/Kotlin 코드와 C/C++ 네이티브 코드 사이를 연결해 주는 통로(Interface)

상호 호출: 안드로이드 프레임워크(Java/Kotlin)에서 작성된 UI나 카메라 API 데이터가 네이티브 영역(C/C++)으로 넘어가 연산되고, 그 결과값이 다시 돌아오는 과정을 관리

데이터 변환: Java 객체와 C/C++ 구조체 간의 메모리 레이아웃이 다르기 때문에, 이를 변환해 주는 브릿지 역할을 수행
