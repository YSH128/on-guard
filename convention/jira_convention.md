# Jira 컨벤션

본 문서는 프로젝트에서 사용하는 Jira 컨벤션 및 Jira 자동화를 정의합니다.

---


## 지라 이슈명 템플릿


- Epic, Task 유형만 사용


| **구분** | **템플릿 (작성 규칙)** | **설명** |
| --- | --- | --- |
| **Epic** | **`[기능명] 큰 단위의 목표`** | 서비스의 주요 기능이나 페이지 단위로 작성 |
| **Task** | **`구체적인 작업 내용 (동사형)`** | 깃랩 브랜치를 만들고 실제 코드를 짜는 단위 |
| **Component** | **`BE`, `FE`, `AI`, `EMB`** | 본인의 파트 선택 |



## 작성 예시


### **Epic 1: [회원] 사용자 인증 및 관리** (Component: `FE`)

- **Task 1:** `feat/회원가입 화면 UI 구현`

- **Task 2:** `doc/회원가입 방법 README.md 정리`


### **Epic 2: [인식] 생성형 영상 검출** (Component: `AI`)

- **Task 1:** `feat/생성형 영상 검출 모델 호출` 

- **Task 2:** `feat/생성형 영상 여부 검출`

- **Task 3:** `feat/생성형 영상일 경우 팝업 호출`


## 이슈 생성 규칙


- 공통

    - 담당자 최소 1명 지정

    - Epic 파트 컴포넌트 설정 필수

    - Task 생성할 때 반드시 Epic에 연결!

    - 지라 1 task = 깃 1브랜치

- 순서

    1. **Epic 생성:** **[회원]**, **[제어]** 같은 큰 주제의 에픽을 먼저 만들기.

    2. **라벨 입력:** 오른쪽 **'컴포넌트'** 칸에 본인 파트(예: `BE`)를 선택.

    3. **Task 연결:**  본인이 할 일을 Task로 만들 때, 반드시 해당 **Epic을 연결**. (이슈 생성 창에 '상위 이슈' 또는 '에픽 링크' 칸이 있습니다.)

    4. **브랜치 생성:** 깃랩 브랜치 명은 지라에서 생성되는 이슈 키(예: `PROJ-12`)를 포함하여 `feat/FE/signup-api-PROJ-12` 처럼 작성

    
    ```bash

    # 예시 (팀 프로젝트 S14P11A404)

    git checkout -b feat/FE/signup-api-S14P11A404-28

    ```


## 스토리 포인트


- 시간 기반 추정과 달리, **작업의 복잡도, 노력, 위험성을 종합적으로 고려한 상대적인 측정 단위**

    - ex_ 코드 스니펫 수정, API 연동 개발 → API 연동 개발에 더 높은 스토리 포인트 부여

- 시간 기반 추정은 모든 팀원의 작업 속도와 전문성이 동일하다고 가정하기 때문에 현실적이지 않음

- 따라서 스토리 포인트를 이용하여 개인들이 갖는 세부 사항을 추상화하여 팀이 실제 작업 완료에 집중할 수 있게 해줌


<aside>

🚨

**피보나치 수열**을 사용하여 포인트 부여

- 상대적 크기의 차이가 명확하게 나타나기 때문에 연속적이 숫자보다 스토리 포인트에 주로 사용

</aside>


- 예시

    - MCP 서버 구축 및 테스트 (8점): 복잡도 매우 높음, 3~4일 소요, 위험도 높음

    - 멀티에이전트 아키텍처 구현 (5점): 복잡도 중간~높음, 2일 소요, 위험도 높음

    - 실시간 채팅 스트리밍 구현 (3점): 복잡도 중간, 1.5일 소요, 위험도 중간~낮음

    - 코드 주석 및 타입 힌트 리팩토링 (1점): 복잡도 낮음, 0.5일 소요, 위험도 낮음


## 스토리 포인트 규칙

- 주관적 판단을 통해서 포인트 부여 (예시 기준)

- 8점 이상 부여 X (8점도 최대한 지양)


# Jira 자동화


### Jira 자동화


- 상위 업무 항목의 컴포넌트&레이블 상속

- 상위 항목 완료 -> 모든 하위 작업을 완료로 이동

- 모든 하위 작업 완료 -> 상위 항목 완료

- 진행 중으로 전환하면 -> 시작 날짜 필드를 현재 날짜로 설정

- 하위 항목의 스토리 포인트 변경 -> 상위 업무 항목의 스토리 포인트 합산
